Why Stealth Pro

Older “contains .md / .well-known” packs break documentation and certificate renewals. This release uses precise path logic.

Secrets & backups

Env files, dumps, keys, htpasswd, and backup suffixes stay dark to the public internet.

Dev privacy

Blocks `.vscode`, `.idea`, `.npmrc`, and Docker/env artifacts when exposed via URL.

Zero app deploy

Paste into Cloudflare Custom Rules. No plugin. No origin rewrite.

Install

Cloudflare → Security → WAF → Custom rules → Create → paste rules/stealth-pro.txt → Action: Block → Deploy.
